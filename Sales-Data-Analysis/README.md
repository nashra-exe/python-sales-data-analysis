\# Sales Data Analysis



A beginner Python project that analyzes sales data using Pandas and Matplotlib.



\## Technologies Used



\* Python

\* Pandas

\* Matplotlib

\* CSV



\## Project Description



This project analyzes a small sales dataset to find useful sales information and identify patterns in product and category performance.



The analysis includes:



\* Total revenue

\* Average sale value

\* Highest individual sale

\* Sales by product

\* Sales by category

\* Units sold by product

\* Top-revenue product

\* Highest-revenue category



The project also uses bar charts to visualize sales performance.



\## Key Findings



\* Total Revenue: ₹235,100

\* Average Sale: ₹23,510

\* Highest Individual Sale: ₹100,000

\* Top Revenue Product: Laptop — ₹200,000

\* Top Revenue Category: Electronics — ₹215,000

\* Most Units Sold: Mouse — 7 units



One interesting finding was that the Mouse had the highest number of units sold, while the Laptop generated the highest revenue because of its higher price.
